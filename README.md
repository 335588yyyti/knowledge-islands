# 知識群島

給全班使用的每日個人挑戰網站，以國小高年級的五科複習為主：國語、數學、自然、社會、英文。

- 學生不需要帳號：用班級代碼、座號和 4 位數密碼登入，在學校平板和家裡都能接續進度。
- 網站與資料庫放在 Cloudflare（Workers + D1，免費方案）。計分在伺服器上，學生無法竄改金幣和點數。
- 每一屆都能沿用：題庫依「版本＋年級＋學期＋科目＋單元」分類，換屆、換出版社都不用重做。

**安裝與使用方式請看 [使用說明.md](使用說明.md)。**

## 功能

**學生端**（`/?c=班級代碼`）
- 五科群島，只出老師勾選「已教過」的單元
- 錯題礁：答錯的題目會進這裡，答對才移除
- 燈塔挑戰：各科混合出題
- 段考衝刺島：顯示考試倒數，只出考試範圍
- 每天第一次過關得印章，並累積連續天數
- 吉祥物「船長波波」會跟著答題換表情；金幣可以在「波波的衣櫃」幫波波換裝

**教師後台**（`/teacher`）
- 學生進度與日常加點：印章和累積金幣換成點數，可以複製清單貼到自己的集點系統
- 弱點觀念與弱點單元診斷，並列出全班最常錯的題目
- 勾選教學進度、設定段考範圍
- 題庫：用 Excel 貼上匯入、內建 AI 出題提示詞、查詢、編輯、停用、刪除
- 新增班級、結業封存、切換課本版本、系統設定、匯出 Excel

## 專案結構

| 路徑 | 用途 |
|---|---|
| `public/index.html` | 學生端頁面 |
| `public/teacher.html` | 教師後台頁面 |
| `src/worker.js` | 後端程式（所有 `/api/*`） |
| `migrations/` | D1 資料表與範例資料 |
| `tests/run.mjs` | 端對端測試（本機資料庫 + 瀏覽器操作） |
| `scripts/deploy.sh` | 部署腳本（GitHub Actions 使用） |
| `.github/workflows/deploy.yml` | 推到 `main` 時自動測試，通過後部署 |

## 開發

```bash
npm install
echo 'TEACHER_PASSWORD="自己設定"' > .dev.vars
npm run dev     # 本機啟動：http://localhost:8787
npm test        # 執行全部測試
```

修改資料表時，在 `migrations/` 新增下一個編號的 `.sql` 檔，不要改已經部署過的檔案。
