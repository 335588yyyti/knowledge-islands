# 知識群島

給全班使用的每日個人挑戰網站，以國小高年級的五科複習為主：國語、數學、自然、社會、英文。

- 學生不需要帳號：用班級代碼、座號和 4 位數密碼登入，在學校平板和家裡都能接續進度。
- 資料存在老師自己的 Google 試算表，用 Google Apps Script 發布成網頁，免費。
- 每一屆都能沿用：題庫依「版本＋年級＋學期＋科目＋單元」分類，換屆、換出版社都不用重做。

## 功能

**學生端**
- 五科群島，只出老師勾選「已教過」的單元
- 錯題礁：答錯的題目會進這裡，答對才移除
- 燈塔挑戰：各科混合出題
- 段考衝刺島：顯示考試倒數，只出考試範圍
- 每天第一次過關得印章，並累積連續天數
- 吉祥物「船長波波」會跟著答題換表情；金幣可以在「波波的衣櫃」幫波波換裝

**教師後台**
- 學生進度與日常加點：印章和累積金幣換成點數，可以複製清單貼到自己的集點系統
- 弱點觀念與弱點單元診斷，並列出全班最常錯的題目
- 勾選教學進度、設定段考範圍
- 匯入題目：從 Excel 貼上，或用內建的 AI 出題提示詞
- 新增班級、結業封存、切換課本版本

## 檔案

| 檔案 | 用途 |
|---|---|
| `Code.gs` | 後端程式（貼到 Apps Script） |
| `Index.html` | 學生端頁面 |
| `Teacher.html` | 教師後台頁面 |
| `appsscript.json` | Apps Script 專案設定（時區、網頁應用程式權限） |
| `使用說明.md` | **安裝步驟與使用方式，從這裡開始** |

## 更新程式

把新版的三個檔案貼到 Apps Script 之後，先執行一次 `setup`（它會補上新欄位，不會動到原本的資料），再依序按「部署 → 管理部署作業 → 編輯 → 版本：新版本」。
